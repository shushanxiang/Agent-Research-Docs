# 测试指引

## 概述

本项目使用 pytest 框架，测试目录 `test/` 分为两层：

- `test/unit/` — 单元测试，通过 mock 隔离外部依赖，**不需要 MongoDB / Milvus / LLM API**
- `test/integration/` — 集成测试，**需要 Docker 中的 MongoDB（端口 27112）和 Milvus（端口 19530）**

## 环境要求

```bash
# 1. 激活 conda 环境
conda activate copilot

# 2. 启动 Docker 容器（集成测试需要）
docker start mongo milvus-standalone milvus-etcd milvus-minio

# 3. 确认服务可用
python -c "from pymongo import MongoClient; c = MongoClient('127.0.0.1', 27112, serverSelectionTimeoutMS=3000); print('MongoDB:', c.server_info()['version'])"
python -c "from pymilvus import connections; connections.connect(host='127.0.0.1', port='19530', timeout=5); print('Milvus OK')"
```

## 运行测试

> 所有命令从 `test/` 目录执行（`conftest.py` 在该目录下）。

### 全部单元测试（快速，无外部依赖）

```bash
cd test && python -m pytest unit/ -v
```

### 全部测试（单元 + 集成）

```bash
cd test && python -m pytest unit/ integration/ -v --ignore=test_make_data --ignore=test_data --ignore=test_py
```

### 仅 P0 相关测试

```bash
cd test && python -m pytest unit/ -v -k "api_selection or tool_manager or pydantic or parameter_validator or loop_detection or prompt_parsing or prompt_versions or prompt_hub or function_util"
```

### 覆盖率报告

```bash
# 终端报告
cd test && python -m pytest unit/ integration/ --cov=../param_extraction --cov=../apis --cov=../tasks --cov=../tools --cov=../prompt --cov=../entity --cov=../models --cov=../use_manager --cov-report=term --cov-config=../.coveragerc --ignore=test_make_data --ignore=test_data --ignore=test_py

# HTML 报告
cd test && python -m pytest unit/ integration/ --cov=../param_extraction --cov=../apis --cov=../tasks --cov=../tools --cov=../prompt --cov=../entity --cov=../models --cov=../use_manager --cov-report=html --cov-config=../.coveragerc --ignore=test_make_data --ignore=test_data --ignore=test_py
```

## 标记系统

| 标记 | 含义 |
|------|------|
| `@pytest.mark.unit` | 单元测试（mock 外部依赖） |
| `@pytest.mark.integration` | 集成测试（需要真实服务） |
| `@pytest.mark.slow` | 慢速测试 |
| `@pytest.mark.p0` | P0 缺陷修复相关 |
| `@pytest.mark.p1` | P1 功能增强相关 |
| `@pytest.mark.p2` | P2 架构升级相关 |
