## 一、项目概述

### 1.1 项目定位

基于 RAG（检索增强生成）架构的建筑行业智能文档助手，覆盖**规范法规查询**与**做法图集问答**两大核心场景，实现文档统一存储、智能检索、知识问答三大能力。

### 1.2 核心指标

| 指标                      | 目标值        |
| :------------------------ | :------------ |
| 规范条款查询平均耗时      | ≤ 30 秒       |
| 图集节点查找平均耗时      | ≤ 1 分钟      |
| 问答结果准确率（Top 3）   | ≥ 85%         |
| 全文检索响应（100万文档） | ≤ 3 秒（P95） |
| 语义问答响应              | ≤ 5 秒（P95） |

## 三、技术选型论证

### 3.1 各组件选型理由

| 组件          | 选型理由                                                     | 替代方案                               |
| :------------ | :----------------------------------------------------------- | :------------------------------------- |
| **MinerU**    | 专为复杂 PDF 设计，支持版面分析（标题/正文/表格/图片分离）、公式识别、OCR，对建筑图集（图文混排）解析效果优异 | PaddleOCR + 自定义版面分析、PDFPlumber |
| **LangChain** | 成熟的 RAG 框架，支持自定义 Retriever、Chain、Agent，社区活跃，与 Chroma/FastAPI 集成成熟 | LlamaIndex、自研框架                   |
| **Chroma**    | 轻量级向量数据库，支持 hybrid search（dense + sparse），本地/服务端部署灵活，与 LangChain 深度集成 | Milvus、Weaviate、Qdrant               |
| **FastAPI**   | 高性能异步框架，原生支持 OpenAPI/Swagger，依赖注入完善，适合构建微服务 | Django REST、Flask                     |
| **Redis**     | 多用途：缓存、队列（Celery Broker）、限流、会话、分布式锁，生态成熟 | RabbitMQ + Memcached                   |
| **BGE-M3**    | 支持 8192 token 长文本，dense + sparse + multi-vector 三重表示，中英混合效果好，建筑专业术语 embedding 质量高 | text2vec、m3e、OpenAI Embedding        |
| **通义千问**  | 中文能力顶尖，对规范条文理解准确，支持长上下文（128K），阿里云部署稳定，合规可控 | GPT-4、文心一言、DeepSeek              |
| **Streamlit** | 快速搭建管理后台和数据可视化界面，Python 原生，适合 MVP 和内部工具 | React/Vue + 独立前端                   |

### 3.2 关键技术决策

#### 决策 1：MinerU 作为统一解析入口

- **背景**：建筑文档包含大量图文混排、表格、扫描版 PDF
- **方案**：MinerU 负责所有文档的首次解析，输出统一 JSON 结构（含 text、images、tables、layout_info）
- **扫描版处理**：MinerU 内置 OCR 对低质量扫描件进行文字提取，复杂场景 fallback 到阿里云/百度 OCR 融合投票

#### 决策 2：BGE-M3 多向量表示

- **Dense Vector**：语义检索，处理同义词、近义词（如"疏散宽度"≈"安全出口宽度"）
- **Sparse Vector**：关键词精确匹配，保证规范编号、图集编号的精确召回
- **Multi-Vector (ColBERT)**：细粒度交互，用于最终重排序（Rerank）

#### 决策 3：Chroma Hybrid Search + Redis 缓存

- **Chroma**：存储 dense + sparse 向量，支持混合检索评分
- **Redis**：缓存高频查询结果（TTL 1小时）、存储 BM25 倒排索引（用于快速关键词过滤）

#### 决策 4：LangChain Agent 编排问答流程

- **规范问答 Agent**：检索 → 版本校验（废止检测）→ 条款组装 → LLM 生成 → 溯源标注
- **图集问答 Agent**：多模态检索 → 图片召回 → 节点描述生成 → 图文组装 → LLM 生成

#### 4.2.2 混合检索策略

```python
class HybridRetriever:
    def __init__(self):
        self.dense_retriever = ChromaDenseRetriever(
            collection_name="regulations",
            embedding_model=BGE_M3_EMBEDDING
        )
        self.sparse_retriever = ChromaSparseRetriever(
            collection_name="regulations"
        )
        self.bm25_retriever = RedisBM25Retriever()  # 基于 RedisSearch 或自研
    
    def retrieve(self, query: str, filters: dict, top_k: int = 10) -> List[Document]:
        # 1. 并行检索
        dense_results = self.dense_retriever.similarity_search(
            query, k=top_k*2, filter=filters
        )
        sparse_results = self.sparse_retriever.similarity_search(
            query, k=top_k*2, filter=filters
        )
        bm25_results = self.bm25_retriever.search(
            query, k=top_k*2, filters=filters
        )
        
        # 2. 融合排序 (RRF - Reciprocal Rank Fusion)
        fused_results = self.reciprocal_rank_fusion(
            [dense_results, sparse_results, bm25_results],
            weights=[0.5, 0.3, 0.2]
        )
        
        # 3. 重排序 (BGE-M3 Cross-Encoder)
        reranked_results = self.rerank(query, fused_results[:top_k*2])
        
        return reranked_results[:top_k]
    
    def reciprocal_rank_fusion(self, results_list, weights, k=60):
        """RRF 融合算法"""
        scores = {}
        for results, weight in zip(results_list, weights):
            for rank, doc in enumerate(results):
                doc_id = doc.metadata["id"]
                if doc_id not in scores:
                    scores[doc_id] = 0
                scores[doc_id] += weight * (1 / (k + rank + 1))
        
        # 按分数排序并去重
        sorted_docs = sorted(scores.items(), key=lambda x: x[1], reverse=True)

        self.llm = TongyiQwen(model="qwen-max")
        self.retriever = HybridRetriever(collection="regulations")
        self.prompt = PromptTemplate.from_template(REGULATION_QA_PROMPT)
    
    def answer(self, question: str, chat_history: List[Message]) -> QAResponse:
        # 1. 检索召回（Top 5）
        retrieved_docs = self.retriever.retrieve(question, top_k=5)
        
        # 2. 版本状态校验（废止检测）
        validated_docs = self.validate_status(retrieved_docs)
        
        # 3. 上下文组装
        context = self.build_context(validated_docs)
        
        # 4. LLM 生成
        chain = self.prompt | self.llm | StrOutputParser()
        answer = chain.invoke({
            "question": question,
            "context": context,
            "chat_history": format_history(chat_history)
        })
        
        # 5. 溯源与关联推荐
        sources = self.extract_sources(validated_docs)
        related_clauses = self.find_related_clauses(validated_docs)
        
        return QAResponse(
            answer=answer,
            sources=sources,
            related_clauses=related_clauses,
            disclaimer="AI 回答仅供参考，请以规范原文和纸质图集为准"
        )
    
    def validate_status(self, docs: List[Document]) -> List[Document]:
        """检测并标记废止条款"""
        for doc in docs:
            if doc.metadata.get("status") == "废止":
                # 查找替代条款
                replacement = self.find_replacement(doc)
                doc.metadata["is_abolished"] = True
                doc.metadata["replacement"] = replacement
        return docs

class ClauseRelationService:
    def build_reference_graph(self):
        """构建条款引用关系图"""
        # 1. 提取引用关系（正则 + LLM）
        for clause in all_clauses:
            refs = self.extract_references(clause.content)
            for ref in refs:
                self.graph.add_edge(clause.id, ref.target_clause_id, type="引用")
        
        # 2. 相似度关联（语义相似条款）
        similar_pairs = self.find_semantic_similarities(threshold=0.85)
        for a, b, score in similar_pairs:
            self.graph.add_edge(a, b, type="语义相似", score=score)
        
        # 3. 存储到图数据库（可选，初期用 PostgreSQL 邻接表）
        self.save_graph()
    
    def get_related_clauses(self, clause_id: str) -> List[RelatedClause]:
        """获取关联条款"""
        # 直接引用
        direct_refs = self.graph.get_neighbors(clause_id, type="引用")
        # 语义相似
        similar = self.graph.get_neighbors(clause_id, type="语义相似")
        return direct_refs + similar
```

## 七、RAG Pipeline 详细设计

### 7.1 规范问答 Pipeline

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                          规范问答 RAG Pipeline                               │
└─────────────────────────────────────────────────────────────────────────────┘

  用户提问："商场疏散宽度怎么算"
       │
       ▼
┌─────────────────┐

│  - Query 扩展：同义词扩展（"疏散宽度"→"安全出口宽度"） │
└─────────────────┘
       │
       ▼
┌─────────────────────────────────────────────────────────────────────────────┐
│  2. 混合检索 (Hybrid Retrieval)                                              │
│                                                                             │
│  ┌─────────────────┐  ┌─────────────────┐  ┌─────────────────┐             │
│  │  Dense Search   │  │  Sparse Search  │  │  BM25 Search    │             │
│  │  (语义相似)      │  │  (关键词匹配)    │  │  (全文索引)      │             │
│  │  Top 20         │  │  Top 20         │  │  Top 20         │             │
│  └─────────────────┘  └─────────────────┘  └─────────────────┘             │
│         │                    │                    │                         │
│         └────────────────────┼────────────────────┘                         │
│                              ▼                                              │
│                    ┌─────────────────┐                                      │
│                    │  RRF 融合排序    │                                      │
│                    │  权重: 0.5/0.3/0.2                                     │
│                    └─────────────────┘                                      │
│                              │                                              │
│                              ▼                                              │
│                    ┌─────────────────┐                                      │
│                    │  Rerank 重排序   │                                      │
│                    │  BGE-M3 Cross-Encoder                                   │
│                    │  Top 10 → Top 5                                         │
│                    └─────────────────┘                                      │
└─────────────────────────────────────────────────────────────────────────────┘
       │
       ▼
┌─────────────────┐
│  3. 版本校验     │
│  - 检查条款状态（有效/废止/即将废止）                  │
│  - 若废止 → 查找替代条款（基于标准编号映射表）          │
│  - 标注废止警告                                       │
└─────────────────┘
       │
       ▼
┌─────────────────┐
│  4. 上下文组装   │
│  - 按相关度排序条款                                   │
│  - 拼接条款原文 + 来源信息                             │
│  - 控制总 token < 4000（预留生成空间）                 │
└─────────────────┘
       │
       ▼
┌─────────────────┐
│  5. LLM 生成     │
│  - Prompt: 规范专家角色 + 回答要求 + 上下文 + 问题      │
│  - 温度: 0.3（低温度保证准确性）                       │
│  - Max Tokens: 2048                                   │
└─────────────────┘
       │
       ▼
┌─────────────────┐
│  6. 后处理       │
│  - 提取引用来源（正则匹配规范编号+条款号）              │
│  - 关联推荐（同章节其他条款、引用条款）                 │
│  - 添加免责声明                                       │
└─────────────────┘
       │
       ▼
  返回结构化回答
```

| 向量数据库性能瓶颈               | 中   | ① Chroma 分 Collection（按规范/图集/企业库）；② 定期 HNSW 索引优化 |
| 扫描版 OCR 准确率不足            | 高   | ① 上传时清晰度检测（<150DPI 拒绝）；② 图像增强预处理；③ 多 OCR 引擎投票 |

## 十一、附录

### 11.1 术语对照

| 术语       | 英文                           | 说明                        |
| :--------- | :----------------------------- | :-------------------------- |
| 规范       | Regulation / Standard          | 国家/行业工程建设标准       |
| 图集       | Atlas                          | 建筑标准设计图集            |
| 节点       | Node                           | 图集中的具体构造详图编号    |
| 条款       | Clause                         | 规范中的具体条文            |
| 结构化解析 | Structured Parsing             | 将非结构化 PDF 转为树形数据 |
| RAG        | Retrieval-Augmented Generation | 检索增强生成                |
| RRF        | Reciprocal Rank Fusion         | 倒数排名融合算法            |
