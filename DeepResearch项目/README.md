项目简介

DeepResearch —— 基于 LangGraph 的深度研究多 Agent 应用

技术栈：LangGraph / LangChain / FastAPI / Redis Streams / Milvus / PostgreSQL / React 19 + TypeScript / Docker

项目简介：面向价值可追溯文档，将用户模糊的研究需求通过[严谨专业的自动化研究流程]转化为带引用溯源的专业研究报告，解决大模型回答「不可控、不可追溯、质量难评估」三大痛点。

**核心贡献**：

1. **Human-in-the-Loop 需求澄清（产品化核心）** —— 设计 5 步需求澄清循环与计划确认 / 重规划状态机，让用户通过与 AI 的多轮对话逐步锁定需求边界，解决"AI 直接给错答案"的信任问题，显著提升输出可控性与用户体验。
2. **质量评估闭环（可度量）** —— 独立设计 LLM-as-Judge 评估框架：端到端 5 维评分 + 组件级 8 类评分、引用逐条校验、幻觉检测，让报告质量可度量、可回归，支撑持续迭代优化。
3. **流式体验与工程稳定性（可落地）** —— 基于 Redis Streams 实现异步任务队列 + SSE token 级实时推送，配合瞬态 / 永久异常分类（20+ 类）、指数退避重试、令牌桶限流与缓存降级，保障长任务体验流畅、系统稳定运行。
4. **多 Agent 编排 + RAG 检索（技术底座）** —— 将单体图重构为「计划 → 研究 → 写作」3 个子图，实现 Plan-and-Execute、Reflection 反思、Critic-Writer 辩论循环；基于 Milvus 构建事实知识库，引入交叉编码器重排与生命周期管理提升检索相关性与时效性。
