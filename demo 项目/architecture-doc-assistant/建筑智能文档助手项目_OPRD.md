# 建筑智能文档助手项目_OPRD

[![Author](https://img.shields.io/badge/Author-🌲⛰️🐘-white.svg)](Author)    	[![Version](https://img.shields.io/badge/Version-0.2-white.svg)](Version) 

#### 【项目背景】

- 项目概述：

  > 建筑行业（设计院/施工单位）日常对接大量设计文档（PDF/图片）、规范、图集，目前依赖文件夹+微信/邮件方式管理，版本混乱、检索困难。
  >
  > 本项目打造**建筑智能文档助手**，实现**统一存储、智能检索、知识问答**三大核心能力，重点覆盖 **规范法规查询** 与 **做法图集问答** 两大场景。
  >
  > 目标：文档查找时间缩短 70% 以上，减少因版本/合规错误导致的返工损失。

- 目标用户：

  > | 用户角色        | 典型场景                               | 解决痛点                             |
  > | --------------- | -------------------------------------- | ------------------------------------ |
  > | 设计师/工程师   | 日常工作频繁查阅规范条款、参考图集节点 | 多份文件间反复切换，查找耗时且易遗漏 |
  > | 施工员/现场人员 | 现场需即时确认施工做法和规范要求       | 无法快速检索，纸质资料不便携带       |
  > | 审图专家/总工   | 审查图纸合规性，沉淀企业标准知识       | 缺乏系统化工具，企业知识难以复用     |

- 核心痛点：

  > - P1  规范和图集数千份，单次条款查找平均耗时 **12 分钟**
  > - P2  规范更新频繁（如防火规范2025新版），设计师常不知道现行有效版本
  > - P3  图集为“图+文”混合，扫描 PDF 无文字层，无法关键词检索
  > - P4  企业自有标准做法散落各处，无法系统化积累和复用
  
- 预期收益：

  > | 指标                       | 目标值                    | 衡量方式     |
  > | :------------------------- | :------------------------ | :----------- |
  > | 规范条款查询平均耗时       | ≤ 30 秒                   | 系统埋点统计 |
  > | 图集节点查找平均耗时       | ≤ 1 分钟                  | 系统埋点统计 |
  > | 问答结果准确率（人工评估） | ≥ 85%（Top 3 含正确答案） | 定期抽样评测 |
  > | 企业图集复用率             | 新员工学习成本降低 60%    | 培训时长对比 |

#### 【产品范围与功能优先级】

**能力域划分**：

- **文档处理**：上传、存储、版本管理、自动分类、OCR/解析
- **文档检索**：关键词全文检索、筛选、图集目录树浏览
- **智能问答**：自然语言问答（规范+图集），含溯源和关联推荐
- **系统管理**：权限控制、操作日志、水印、通知
- **知识沉淀**：企业私有图集库、跨图集对比、导出

#### 【用户故事 与核心流程】

**用户故事**

| 用户角色           | 用户故事                                                     | 对于AC |
| :----------------- | :----------------------------------------------------------- | ------ |
| 作为**设计师**     | 用自然语言问“商场疏散宽度怎么算”，系统直接给出公式和规范条款 | AC-08  |
| 作为**结构工程师** | 查“最小配筋率”时，系统展示多本规范相关条款并标注异同         | AC-09  |
| 作为**建筑设计师** | 问“屋面防水节点做法”，系统返回不同图集节点图+说明            | AC-10  |
| 作为**施工员**     | 现场用手机查图集节点，快速确认做法                           | AC-12  |
| 作为**总工程师**   | 上传企业标准做法，形成私有图集库，供团队复用                 | AC-13  |

**主流程图**

规范问答流程：

```
规范PDF上传 → 结构化解析（章节/条款） → 版本状态标注 → 建立全文+向量索引
     ↓
用户提问 → 语义理解 → 检索召回（关键词+向量） → 重排序 → 返回条款原文+来源 → （若废止则提示替代）
```

图集问答流程：

```
图集PDF上传 → 解析目录/节点 → 提取文字+图片 → 建立图文联合索引（含OCR）
     ↓
用户提问 → 多模态检索 → 返回节点图片+文字描述+图集编号 → 支持对比/导出
```

**异常分支**

| 异常场景                         | 系统行为                                                  |
| :------------------------------- | :-------------------------------------------------------- |
| 上传同名但内容不同的文件         | 检测哈希值，提示“内容不同，请选择：覆盖/另存新版本/取消”  |
| 提问涉及已废止条款               | 回答中标注“已废止”，并显示现行替代条款（若存在）          |
| 上传纯扫描版图集（无文字层）     | 自动触发 OCR 异步任务，完成后通知用户，期间可浏览目录结构 |
| 提问无精确匹配节点               | 返回最相似 3 个节点，标注相似度，并提供参考建议           |
| 图集文件过大（>100MB）或页数过多 | 支持分片上传，解析任务排队处理，推送进度通知              |
| 图片清晰度不足导致 OCR 失败      | 提示“清晰度不足，建议重新扫描该页”，并保留人工补充入口    |

#### 【非功能需求】

- 性能：

  | 指标                      | 目标值                                                       |
  | :------------------------ | :----------------------------------------------------------- |
  | 全文检索响应（100万文档） | ≤ 3 秒（P95）                                                |
  | 语义问答响应              | ≤ 5 秒（P95），复杂跨库查询 ≤ 10 秒                          |
  | 图集预览加载（100页）     | 首屏 ≤ 3 秒，翻页 ≤ 1 秒                                     |
  | 单文件上传限制            | 最大 200MB（支持分片），批量最多 20 个/次                    |
  | 图集解析吞吐              | 常规 PDF（含文字层）100 页 ≤ 10 分钟；扫描版 OCR 异步处理，不计入同步等待 |

- 安全：

  > - **审计日志**：所有上传、查询、下载、删除操作记录，日志保留 180 天，不可篡改（区块链摘要可选）。
  > - **合规声明**：所有 AI 回答底部固定显示“AI 回答仅供参考，请以规范原文和纸质图集为准”。
  
- 兼容性：

  > - 网页端：Chrome/Edge/Firefox最新两版
  > - 文件格式：PDF、JPG、PNG、TIFF、DOC/DOCX、XLS/XLSX、PPT/PPTX、TXT、ZIP/RAR（压缩包自动解压索引）

#### 【风险与依赖】

| 风险类别     | 风险描述                                          | 应对措施                                                     |
| :----------- | :------------------------------------------------ | :----------------------------------------------------------- |
| **外部依赖** | OCR 服务对建筑图集特殊字体/尺寸标注识别准确率不足 | ① 引入多家 OCR（如阿里云+百度）融合投票；<br />② 建立人工标注反馈机制，持续优化模型；<br />③ 对关键图集提供人工补充修正入口 |
| **外部依赖** | 规范电子版数据源依赖第三方，更新不及时            | ① 同时对接国家标准化信息中心 API 和手动上传两条路；<br />② 建立社区众包更新机制（用户可提交更新提醒） |
| **外部依赖** | 国标图集版权授权谈判周期长                        | ① 前期仅支持企业自有已购图集，用户自行上传；<br />② 平台提供“仅企业内部使用”声明，不公开传播 |
| **技术风险** | 大型图集（>500页高分辨率）预览加载慢              | ① 采用图片切片+懒加载，按需渲染可见区域；<br />② 预生成低分辨率缩略图；<br />③ 支持离线缓存压缩包 |
| **技术风险** | 规范条款引用网络复杂，知识图谱构建耗时            | ① 先使用文本相似度自动发现引用关系，再辅以人工抽样校验；<br />② 初期不追求完整图谱，仅支持直接引用跳转，逐步迭代 |
| **技术风险** | 扫描版图像质量参差不齐                            | ① 上传时自动检测 DPI 和清晰度，不合格则提示；<br />② 内置图像增强预处理（去噪、二值化） |
| **法务合规** | AI 回答可能误导用户造成工程事故                   | ① 在所有回答页面醒目标注免责声明；<br />② 提供“查看原文”按钮强制用户核对纸质原版；<br />③ 不替代专业工程师判断 |
| **业务风险** | 中小型项目用户不买单                              | ① 定位中大型项目及集团客户，提供定制化部署；<br />② 先免费试用 1 个月，展示 ROI 数据 |
